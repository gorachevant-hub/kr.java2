# Собственные формулировки (раздел 12)

1. Проверка amount < 0 и risk == null находится в ApprovalRouter.route до выбора маршрута.
2. Главная часть — метод route. Он проверяет условия по порядку и возвращает первый подходящий маршрут.
3. На схеме условия идут так же, как в методе: персональные данные, высокий риск, сумма, срочность.
4. Для изменения порога суммы достаточно поменять FINANCE_LIMIT.
