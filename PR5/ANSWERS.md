# Анализ фрагмента из задания

Ошибка в условии i <= hours.length: последняя итерация обращается к несуществующему индексу hours.length. Нужно i < hours.length.

# Собственные формулировки (раздел 12)

1. Проверка ровно пяти элементов и диапазона 0–16 находится в parseHours; неверное значение сопровождается номером позиции.
2. Разбор строки и подсчёты я оставил в TimesheetAnalyzer: этот класс работает с часами из табеля.
3. Сначала строка делится по `;`. Если значений не пять или какое-то число неверное, программа выдаёт ошибку и не считает итог.
4. Если поменяется максимум часов за день, достаточно изменить DAILY_LIMIT.
